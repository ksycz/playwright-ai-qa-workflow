Questions where the requirements don't define the value
1. Is a field of only spaces "empty" (M1) or "any other invalid age" (M2)?
2. At 10 tickets, does an empty field show M1, M2 or M3? REQ-1.3 says "the invalid-age message", but REQ-1.2 has two messages.
3. REQ-1.2 gives only 007 as a leading-zero example. Are 000, 0120 and very long zero-padded values accepted, and is 0121 refused as 121? The table also assumes 007 is read as 7, which the requirement implies but doesn't state.
4. Do tabs and non-breaking spaces count as "spaces", and do non-ASCII digits such as full-width ３０ count as "digits"?
5. Is the group discount recalculated when a removal takes the order below 8? The last table row reads REQ-1.4's "all prices and the total are already correct" as yes, but REQ-2.5 doesn't say so.
